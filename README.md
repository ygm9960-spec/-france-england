# 태양왕이 여왕이 되었다 · v0.43

모바일 가로 화면용 역사 수업 웹앱입니다. 이 폴더 전체를 GitHub Pages 저장소 루트에 업로드하여 기존 배포 파일을 덮어씁니다. `index.html`, `css/`, `js/`, `images/`, `audio/`, `sw.js`를 모두 함께 업로드하세요.

메인 화면의 빈 공간을 포함한 첫 탭에서 오리지널 연주곡이 시작됩니다. 시작 버튼을 누르지 않아도 재생하며, 게임 화면으로 넘어가면 타이틀 음악은 중지합니다. 모바일 브라우저에서는 첫 탭 전 소리를 자동 재생할 수 없습니다.

교사용 메뉴: 메인 화면 제목, 게임 내 상단 장면 제목 또는 디베이트 상단 제목을 빠르게 5회 탭합니다. 교사용 미리보기 중에는 별도 종료 버튼이 나타납니다.

버전별 변경사항은 `CHANGELOG.md` 한 파일에 통합되어 있습니다.
